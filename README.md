# 🌌 안티그래비티 코스믹 미로탈출 웹앱 (Zero-G Maze Escape)

학생 과제, 동아리 프로젝트, 알고리즘 실습 및 포트폴리오 제출에 최적화된 **웹 기반 미로 탈출 게임**입니다.

---

## 🎮 주요 기능 및 특징

1. **절차적 미로 자동 생성 (DFS 알고리즘)**
   - 매판 완전히 새로운 형태의 유일 탈출 경로를 가진 완벽한 미로(Perfect Maze)를 생성합니다.
2. **2가지 이동 모드 제공**
   - **반중력 관성 모드 (🛸 기본값):** 우주 무중력 상태처럼 벽에 부딪힐 때까지 쭉 미끄러지는 스릴 넘치는 모드
   - **일반 탐험 모드 (🚶):** 방향키마다 정밀하게 1칸씩 탐험하는 클래식 모드
3. **최단 경로 힌트 시각화 (BFS 알고리즘)**
   - 탈출로를 찾기 어려울 때, 너비 우선 탐색(BFS)으로 계산된 최단 탈출로가 노란색 점선으로 표시됩니다.
4. **시야 제한 안개 모드 (Fog of War 🔦)**
   - 플레이어 주변 반경만 보이는 탐험등 모드로 긴장감 넘치는 플레이 가능
5. **무외부 의존성 사운드 (Web Audio API)**
   - MP3 파일 다운로드 없이 브라우저 자체 오디오 신디사이저로 발걸음음, 슬라이드음, 벽 충돌음, 승리 팡파레 자동 생성
6. **완벽한 반응형 & 모바일 지원**
   - PC: 키보드 방향키 또는 `W`, `A`, `S`, `D`, `R`(리셋), `H`(힌트)
   - 모바일: 화면 터치 스와이프 제스처 및 가상 D-Pad 컨트롤러 제공
7. **기록 저장 (LocalStorage)**
   - 난이도 및 모드별 최단 클리어 기록 자동 저장

## 🚀 실행 방법

### 방법 1: 브라우저에서 바로 열기
1. 탐색기에서 `index.html` 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge) 등의 웹 브라우저에서 바로 플레이할 수 있습니다.

### 방법 2: 로컬 웹 서버 실행 (VS Code 또는 터미널)
- VS Code를 사용하는 경우: **Live Server** 확장을 설치하고 `index.html`에서 우클릭 → `Open with Live Server`
- 또는 Python이 설치되어 있다면 폴더 내에서 실행:
  ```bash
  python -m http.server 8080
  ```
  이후 브라우저에서 `http://localhost:8080` 접속

## 🧠 학생 발표 및 과제용 핵심 알고리즘 설명

### 1. 미로 생성: 깊이 우선 탐색 (DFS / Recursive Backtracker)
- **원리:**
  1. 모든 격자를 벽(0)으로 초기화합니다.
  2. 시작점 `(1, 1)`에서 상·하·좌·우 2칸 거리의 미방문 셀을 무작위로 고릅니다.
  3. 선택한 방향의 벽을 허물고 길(1)로 연결한 뒤, 해당 좌표를 스택(Stack)에 넣습니다.
  4. 더 이상 방문할 곳이 없으면 스택에서 이전 좌표를 꺼내어 되돌아옵니다(Backtracking).
  5. 스택이 빌 때까지 반복하여 고립된 구역 없이 모든 길이 하나로 연결된 미로를 만듭니다.

### 2. 최단 경로 탐색: 너비 우선 탐색 (BFS / Breadth-First Search)
- **원리:**
  - 큐(Queue) 자료구조를 이용하여 현재 플레이어 위치에서 출발해 인접한 상하좌우 통로를 레벨 단위로 확장 탐색합니다.
  - 목표 지점(포탈)에 처음 도달했을 때의 경로가 수학적으로 보장되는 최단 경로가 됩니다.
  - 이를 캔버스 위에 점선(`setLineDash`)으로 렌더링하여 실시간 힌트를 제공합니다.

### 3. 무중력(반중력) 관성 물리 로직
- 플레이어가 방향키를 한 번 누르면, 앞쪽이 벽(`maze[y][x] === 0`)이 아닐 때까지 `while` 루프와 `setTimeout` 기반의 비동기 애니메이션으로 연속 전진합니다.
